# Tune In — iPhone Web App

A swipeable iOS-style youth discussion app. Files are self-contained and run in a browser.

## Publish with GitHub Pages

1. Make a new **public** repository (GitHub Free Pages requires public).
2. Upload the six site files at the top level of the repository, NOT the ZIP or enclosing folder.
3. Open repository **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, **main**, **/(root)**, and **Save**.
5. Once published, open `https://YOUR-USERNAME.github.io/YOUR-REPO/` on the iPhone using Safari.
6. **Share → Add to Home Screen**, enable **Open as Web App**, and tap **Add**.
7. Launch once while online to allow the service worker to cache the app.
8. Test in airplane mode **before** your presentation. Offline reliability depends on iOS caching and storage.
9. Mirror the iPhone to the projector using iOS Control Center → Screen Mirroring.

**Warning:** GitHub Pages is internet hosting. The *installed app* can run from offline cache after a first online visit. This does not turn GitHub into a local server on the iPhone.

The app contains fictional characters and simulated notifications, not real iMessage.
